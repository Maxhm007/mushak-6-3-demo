# Mushak 6.3 demo

Public demo of the Mushak 6.3 generator. The first visit in a browser opens a sample book: an issued challan, a cancelled number, a supply with supplementary duty, and a draft. What you type stays in that browser.

Remove the sample book before you start a real series.

The source repository stays private. This repository is the built site only.

This demo does not file returns on vat.gov.bd, and it is not National Board of Revenue enlisted software.
